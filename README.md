<a name="specifiche"></a>
## 🛠️ Specifiche Tecniche

- **Grafica & Simulazioni:** Canvas HTML5 2D/3D/4D matematico senza motori terzi
- **Audio Engine:** Sintesi sinusoidale nativa tramite Web Audio API
- **Tipografia:** Cinzel (titoli), Plus Jakarta Sans (testo), Space Mono (dati)
- **Privacy:** Vedi sezione dedicata
