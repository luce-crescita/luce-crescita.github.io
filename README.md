## 🛠️ Specifiche Tecniche

* **Grafica & Simulazioni:** Canvas HTML5 2D/3D/4D matematico senza motori terzi (Three.js-free, zero overhead).
* **Audio Engine:** Sintesi sinusoidale nativa tramite **Web Audio API**.
* **Tipografia:** *Cinzel* (titoli e astri), *Plus Jakarta Sans* (testo corrente), *Space Mono* (dati e codice).
* **Privacy:** Nessun cookie di profilazione, nessun tracker di terze parti, salvataggio locale esclusivo tramite `localStorage`.
